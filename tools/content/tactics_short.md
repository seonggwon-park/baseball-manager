# 숏폼 "번트, 정말 손해일까?" (시제품, 52초)

세로 1080×1920, 30 fps. 화면 글자만으로 이해되게 만들었다. 가상 선수, 가상 리그의 결과다. 목소리를 넣는다면 아래 내레이션을 쓴다.

```sh
cargo run --release --bin bm -- rollout --states 300 --rollouts 200 --seed 2025 --json rollout.json
# 도입부 그림: tools/render의 번트(124_08, bat_close 카메라) 프레임 폴더
HOOK_LAST=45 python3 -I tools/content/tactics_short.py rollout.json out/bunt/bat_close short.mp4
```

## 표시와 권리

- 3D 장면에는 "3D 시뮬레이션 · 가상 선수"를, 나머지 장면에는 "가상 선수 · 가상 리그 시뮬레이션"을 늘 띄운다.
- 모션은 CMU 데이터베이스 출처를 끝 화면에 적는다([`tools/render/README.md`](../render/README.md)의 '자료와 권리').
- 색은 어두운 바탕 `#1a1a19`에서 색각 이상 시뮬레이션과 대비 검사를 통과한 파랑 `#3987e5`·빨강 `#e66767` 두 색만 쓴다. 글자는 글자 색(밝은 회색 계열)으로만 쓴다.
- 쇼츠·릴스는 아래쪽(채널 이름·설명)과 오른쪽(좋아요·댓글 단추)을 앱이 덮는다. 일반 게시물의 안전 영역은 공식 수치를 찾지 못했고, 제3자 안내의 추정은 아래 300–672 px, 오른쪽 96–192 px로 갈린다(메타가 릴스 광고에 권한다는 값은 위 14%, 아래 35%). 그래서 글자와 숫자를 y 220–1500, x 80–900 안에 두었다. 올리기 전에 실제 기기에서 확인한다.
