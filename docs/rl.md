# 강화학습 환경 (bm-gym, 2026-11-20)

게임과 시뮬레이션은 같은 엔진을 쓴다. 이 환경은 그 엔진 위에서 감독의 결정을 학습하고 탐색하는 도구다. Rust 크레이트 `bm-gym`이 환경 본체이고, Python 패키지 `python/bm_gym`이 그것을 Gymnasium 인터페이스로 내보낸다.

**여기서 배운 결과는 엔진에 대한 것이다.** 학습 알고리즘은 시뮬레이터의 허점을 파고든다(명세 게이밍, Krakovna et al. 2020). 엔진에서 이기는 작전이 실제 야구에서도 이긴다고 말하려면, 그 작전이 기대는 엔진의 부분이 실측과 맞는지 따로 확인해야 한다. 엔진의 전술 영역 검증은 [`tactics.md`](tactics.md)에 있다.

## 1. 에이전트가 하는 일

에이전트는 한 구단의 공격을 맡는다. 자기 타자에게 공이 하나 던져지기 전마다 두 가지를 고른다.

- 타격 접근 5가지: 강공(`hit`), 희생번트(`sac_bunt`), 기습번트(`bunt_for_hit`), 히트 앤드 런(`hit_and_run`), 기다리기(`take`)
- 도루 지시 3가지: 주자 판단(`auto`), 금지(`hold`), 이번 투구에 출발(`steal`)

행동은 둘의 조합 15가지다(`approach × 3 + steal`). 나머지는 엔진의 AI 감독(`mlb` 성향, `tactics.md` 3절)이 한다. 상대 구단의 모든 결정과, 에이전트 구단의 투수 교체·대타·대주자·수비 위치·고의사구가 여기에 들어간다. 한 경기가 한 에피소드이고, 경기당 결정은 평균 149번이다(자기 공격의 투구 수).

- **공격만 맡기는 이유:** 엔진의 위임 플래그(`Auto`)가 수비 위치와 고의사구를 한 묶음(`defense`)으로 다룬다. 에이전트에게 고의사구만 주려면 이 묶음을 나눠야 한다. 엔진 수정이 필요해서 다음 단계로 미뤘다.
- **번트 방향:** AI 감독처럼 70%를 3루 쪽으로 댄다.
- **경기:** 메이저리그 구장 30곳(2025 MLB 규칙)과 능력치로 만든 구단 30개다(`bm validate --world`와 같은 선수 생성). 경기마다 두 구단과 맡을 쪽(원정·홈)을 무작위로 뽑는다. 구단은 `league_seed`로 정해지며, CLI의 같은 `--seed`와 같은 구단이다.

### 행동 마스크

상황에 맞지 않는 행동은 마스크로 알려 준다(`action_mask()`, Gymnasium 래퍼의 `info["action_mask"]`와 `action_masks()`; sb3-contrib MaskablePPO의 관례).

- 도루 지시(금지·출발): 보낼 주자가 있을 때만. 1루 주자와 빈 2루, 또는 2루 주자와 빈 3루.
- 희생번트: 1루나 2루에 주자가 있고 2아웃 미만일 때만.
- 히트 앤드 런: 보낼 주자가 있을 때만. 주자를 스스로 보내므로 도루 지시는 '주자 판단'과만 짝짓는다.

마스크 밖의 행동은 거부하지 않고 가장 가까운 행동으로 바꿔 실행한다. 먼저 도루 지시를 '주자 판단'으로 바꾸고, 그래도 안 되면 강공으로 바꾼다.

## 3. 보상: 승리 기대값의 변화

기본 보상은 한 단계 동안 에이전트 구단의 승리 기대값이 바뀐 양이다. 마지막 단계에서 승리 기대값은 이기면 1, 지면 0이 된다. 그래서 한 경기의 보상 합은 '결과 − 첫 결정 때의 승리 기대값'이다. 이것은 승리 기대값을 잠재 함수로 쓴 보상 성형이고, 표가 틀려도 최적 정책은 바뀌지 않는다(Ng, Harada & Russell 1999). 좋은 표는 학습만 빠르게 한다. `reward="win"`을 주면 이긴 경기의 끝에만 1을 준다.

### 승리 기대값 표 (`bm we`)

`data/engine/win_expectancy.json`은 AI 감독끼리 치른 30만 경기(타석 2,267만 개, 4스레드로 599초)에서 센 표다. 칸은 이닝(1–9, 연장은 하나로) × 초·말 × 아웃 × 주자 상태 × 홈팀 점수차(±10에서 자름), 모두 10,080칸이다. 각 칸에 그 상태에서 시작한 타석 수와 그 가운데 홈팀이 이긴 수를 둔다. 표본이 적은 칸은 같은 이닝·초말·점수차를 아웃·주자 상관없이 묶은 값으로 당긴다. 그 묶음은 다시 초말·점수차만으로 묶은 값으로 당긴다(각 가중 타석 20개).

| 상황 (타석 시작) | 홈팀 승리 기대값 |
|---|---|
| 경기 시작 | 0.502 |
| 9회초, 홈 1점 앞섬, 주자 없음, 무사 | 0.848 |
| 9회말, 동점, 주자 없음, 무사 | 0.633 |
| 9회말, 동점, 1루, 무사 | 0.694 |
| 9회말, 동점, 2루, 1사 | 0.687 |
| 9회말, 1점 뒤짐, 만루, 2사 | 0.276 |
| 5회초, 홈 3점 앞섬, 주자 없음, 무사 | 0.858 |

- 엔진에는 말 공격의 이점 말고는 홈 이점이 없다. 그래서 경기 시작 때 홈팀 승리 기대값이 0.502다. 실제 MLB에서는 홈팀이 이보다 더 많이 이긴다.
- 이 표는 엔진의 AI 감독끼리의 표다. 에이전트가 다르게 지휘하면 실제 승리 확률은 표와 달라진다. 보상 성형에는 문제가 없다(위).
- 엔진을 바꾸면 표가 낡는다. `cargo run --release --bin bm -- we --games 300000`으로 다시 만든다.

## 4. 같은 순간을 여러 갈래로

환경은 진행 중인 경기째로 복제된다(Rust `ManagerEnv::clone`, Python `copy()`). 그래서 한 결정 시점에서 행동마다 같은 상태로 갈라 끝까지 시뮬레이션해, 행동의 값을 직접 잴 수 있다. `finish_with_ai()`는 남은 경기를 AI 감독에게 맡겨 끝까지 치르고 승패를 돌려준다. Rust의 `ManagerEnv::rollout`은 지금 타석을 주어진 지시로 치른 뒤 나머지를 AI 감독에게 맡기고, 승패와 그 이닝 남은 득점을 돌려준다. `bm rollout`(6절)이 이것을 쓴다.

## 5. 쓰는 법

```sh
# Rust: 환경 테스트와 승리 기대값 표
cargo test -p bm-gym
cargo run --release --bin bm -- we --games 300000

# Python (Rust 툴체인 필요; maturin이 crates/bm-py를 빌드한다)
pip install "./python[gym]"        # 개발 중이면: cd python && maturin develop --release
pytest python/tests
```

```python
import bm_gym
env = bm_gym.make(seed=1)                 # gymnasium.Env (또는 gymnasium.make("BaseballManager-v0"))
obs, info = env.reset(seed=7)
while True:
    mask = info["action_mask"]
    action = 0                            # 0 = 강공 + 주자 판단
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated:
        break
print(info["won"], info["score"])
```

- **속도:** 이 컨테이너의 한 스레드에서 Python 바인딩은 초당 약 18,500결정(경기 125개)이고, Gymnasium 래퍼는 17,100결정이다. 엔진만 돌리면 경기당 8ms다(`bm validate`).
- **결정론:** 같은 `reset(seed)`와 같은 행동은 같은 경기를 만든다.

## 6. 작전 롤아웃: 엔진 안에서 작전 하나의 값

`bm rollout`은 경기에서 실제로 나온 타석 시작 순간을 상황별로 모은다. 그리고 그 순간을 복제해 작전마다 끝까지 시뮬레이션한다. 작전은 그 타석에만 쓰고, 다음 타석부터는 AI 감독이 지휘한다. 작전마다 같은 난수를 준다(공통 난수). 이것은 AI 감독을 기준 정책으로 한 롤아웃 정책 개선의 한 단계다(Tesauro & Galperin 1997). 상황마다 타석 300개, 작전마다 롤아웃 200번(4스레드로 1,152초)이다. 타석은 에이전트 구단이 늘 강공하고 주자는 스스로 판단하는 경기에서 뽑았다(공격 타석의 25%를 무작위로).

작전(그 타석에서):

- 희생번트: 2스트라이크 전까지 번트, 그 뒤 강공
- 기습번트: 첫 투구만 번트
- 도루: 첫 투구에 선두 주자를 보냄(주자의 판단과 상관없이)
- 히트 앤드 런: 첫 투구에
- 주자 묶기: 타석 내내 도루 금지

강공 대비 차이다. 타석별로 (작전 − 강공)을 구한 뒤 타석 평균을 냈고, ±는 타석 간 표준오차다. '득점'은 그 이닝이 끝날 때까지의 득점이다.

| 상황 (타석 시작) | 강공: 승리 / 득점 | 희생번트 | 도루 | 히트 앤드 런 | 주자 묶기 |
|---|---|---|---|---|---|
| 1루, 무사, 1–6회, 점수차 1 이하 | 0.568 / 0.820 | −0.97%p ± 0.28 / −0.071 | −2.80%p ± 0.30 / −0.226 | −1.30%p ± 0.30 / −0.071 | −0.45%p ± 0.28 / −0.005 |
| 1루, 무사, 7회 이후, 점수차 1 이하 | 0.583 / 0.793 | −0.48%p ± 0.25 / −0.070 | −3.78%p ± 0.30 / −0.222 | −0.93%p ± 0.25 / −0.083 | −0.36%p ± 0.25 / −0.005 |
| 2루, 무사, 7회 이후, 점수차 1 이하 | 0.598 / 0.985 | −1.22%p ± 0.28 / −0.085 | 3루 도루 −9.85%p ± 0.43 / −0.385 | | +0.03%p ± 0.26 / −0.012 |
| 1·2루, 무사, 7회 이후, 점수차 1 이하 | 0.662 / 1.250 | +0.06%p ± 0.27 / −0.003 | | | |
| 1루, 1사, 7회 이후, 점수차 1 이하 | 0.532 / 0.466 | −1.64%p ± 0.28 / −0.079 | −2.61%p ± 0.29 / −0.152 | −0.88%p ± 0.25 / −0.049 | |
| 1루, 2사, 모든 이닝 | 0.528 / 0.219 | | −0.78%p ± 0.23 / −0.104 | | −0.13%p ± 0.20 / +0.002 |

주자 없음·무사의 기습번트는 승리 +0.00%p ± 0.24, 득점 +0.003이다. 득점 칸의 표준오차는 0.005–0.013점이다.

- **강공보다 나은 작전은 없었다.** 가장 나은 것이 본전이다. 1·2루 무사의 희생번트(+0.06%p), 기습번트(0.00%p), 2사 1루에서 가장 빠른 주자 1/3의 도루(+0.5%p ± 0.4)가 그렇다.
- **희생번트는 1루나 2루 주자만 있을 때 0.5–1.6%p를 잃는다.** 타자의 공격 가치를 셋으로 나눠도 어느 쪽도 이득이 아니다. 1루 무사·후반의 약한 타자 1/3도 −0.3%p ± 0.4다. 대상은 지명타자 규칙 아래의 야수들이다(투수 타석 없음).
  - 엔진은 1루 무사 번트 성공의 손실을 실제보다 작게 본다(득점 기대값 −0.153, Tango 2010–2015 표 −0.195; `tactics.md` 2절). 그러니 실제라면 이 번트는 더 손해일 것이다.
  - 1·2루 무사 번트가 본전에 가까운 것은 표와 맞는다. 성공한 번트의 득점 기대값 변화가 −0.061(Tango)로 작고, 한 점이라도 날 확률은 +0.066이다(엔진 +0.052, 실제보다 조금 작음).
- **도루를 무조건 시키면 손해다. 주자 스스로의 판단은 조금 이득이다.** 득점 변화를 엔진의 득점 기대값 표로 거꾸로 풀면, 1루 무사에서 첫 투구 도루의 성공률은 약 41%다. 가장 빠른 주자 1/3은 약 65%다. 둘 다 손익분기(68.4–69.8%, `tactics.md` 2절)보다 낮다. 엔진의 주자는 시간 여유가 있을 때만 스스로 뛰고, 그렇게 뛴 도루의 성공률은 76.9%다. 그래서 도루를 막으면(주자 묶기) 0.3–0.7%p를 잃는다.
  - 주자 주력별로 1루 무사·초반 도루: 느린 1/3 −4.7%p, 가운데 −3.4%p, 빠른 1/3 −0.3%p ± 0.5.
  - 3루 도루(2루 무사)는 주력과 상관없이 −8–−13%p다. 무사 3루 도루의 손익분기가 78.7%로 높기 때문이다.
- **AI 감독의 번트는 얼마나 손해인가.** AI 감독은 2025 MLB 빈도에 맞춰, 1–8회 주자가 있는 상황에서 경기당 0.37번(양 팀 합계) 번트를 시도한다(`tactics.md` 3절). 상황별 시도 횟수에 위 표의 손실을 곱하면 팀 경기당 약 0.16%p, 162경기에 약 0.25승이다. 작다.
- **이것이 말하지 않는 것:** 한 가지 작전을 그 타석에만 바꾼 값이다. 상대가 번트 수비를 바꾸거나, 볼카운트에 따라 작전을 바꾸는 효과는 들어 있지 않다. 엔진의 번트·도루 모델(성공 분포, 리드와 출발)은 리그 빈도와 결과에 맞췄을 뿐, 상황별 성공률을 따로 검증하지는 않았다.

## 7. 강화학습 시연: 표 형태 학습기 셋

`python/examples/q_learning.py`는 Python 환경 위에서 표 형태 학습기를 돌린다. 상태는 일부러 거칠게 잡았다. 아웃 × 주자 × 볼카운트 × '후반 접전'(7회 이후, 점수차 1 이하) 여부 × 타자(관찰의 `batter_quality`로 약·보통·강)이고, 모두 1,728칸이다. 보상은 승리 기대값의 변화다. 학습에 4만 경기(약 530만–670만 결정, 한 스레드로 355–400초)를 쓰고, 같은 시드 2만 경기로 비교했다. 시드가 같으면 구단·구장·맡는 쪽이 같다. ±는 경기별 짝 차이의 표준오차다.

| 정책 | 승률 | 항상 강공 대비 |
|---|---|---|
| 항상 강공(`hit`) | 0.5029 | |
| AI 감독(`ai`, 공격 작전도 AI) | 0.5019 | −0.10%p ± 0.49 |
| Q-학습(한 표, 고정 학습률 0.05) | 0.3689 | −13.41%p ± 0.48 |
| 이중 Q-학습(학습률 1/n) | 0.2544 | −24.85%p ± 0.46 |
| 몬테카를로 + 신중한 정책 | 0.4980 | −0.49%p ± 0.24 |

- **AI 감독의 공격 작전은 항상 강공보다 낫지 않다.** 차이 −0.10%p ± 0.49는 잡음 안이다. 6절의 롤아웃 어림(시즌 약 0.25승 손해, 경기당 −0.16%p)과도 어긋나지 않는다.
- **Q-학습은 거의 모든 볼카운트에서 '기다리기'를 배웠다.** 잡음 섞인 추정값 15개의 최댓값을 다음 상태의 값으로 쓰면 값이 위로 쏠린다(최대화 편향, Sutton & Barto 2018 6.7절). 타석을 길게 끄는 행동일수록 그 쏠림이 여러 번 쌓여 좋아 보인다.
- **이중 Q-학습(Hasselt 2010)은 최대화 편향을 줄이지만 다른 함정에 빠졌다.** 학습률 1/n은 모든 목표값을 같은 무게로 평균한다. 그래서 다음 상태의 값을 아직 0으로 알던 초기의 목표값이 끝까지 남는다. 이 문제에서 정상 행동의 값은 음수로 내려가므로(탐험 중의 손해가 섞인다), 덜 시도한 작전일수록 0에 가까운 낙관적인 값을 유지한다. 탐욕 정책은 그런 작전(도루, 번트, 히트 앤드 런)을 고른다.
- **몬테카를로 제어**는 행동 뒤에 실제로 따라온 반환값의 평균으로 값을 매긴다. 부트스트랩을 하지 않으므로 위의 두 편향이 없다. 다른 작전이 강공보다 2 표준오차 넘게 나을 때만 강공을 떠나게 했다(탐험률 0.15). 1,728칸 가운데 강공을 떠난 칸은 하나뿐이었다. 2아웃·주자 없음·1-0·약한 타자에서 기습번트로, 학습 중 추정은 +2.1%p였다. 그런데 평가에서 이 정책은 강공보다 0.49%p ± 0.24 나빴다. 칸 1,728개마다 대안 여러 개를 2 표준오차로 견주면 우연히 그 선을 넘는 칸이 나온다(다중 비교). 그 하나가 거짓 발견이었다. 결국 세 학습기 모두 강공보다 나은 정책을 찾지 못했다. 6절의 롤아웃 결론(강공보다 나은 작전이 없음)과 같다.
- **교훈:** 이 문제에서 행동 간 차이는 승리 확률 0.5–5%p다. 한 경기 결과의 잡음(표준편차 0.5)에 비해 아주 작다. 그래서 학습기의 작은 편향이 결과를 뒤집는다. 같은 상태를 복제해 공통 난수로 비교하는 6절의 롤아웃이 이 질문에는 더 믿을 만한 도구다. 강화학습으로 더 나아가려면 볼카운트를 넣은 잠재 함수, 함수 근사, 훨씬 많은 표본이 필요하다.

## 8. 한계

- 상대 AI 감독은 고정되어 있고 적응하지 않는다. 에이전트가 찾은 작전은 그 상대에 대한 답이다. 적응하는 상대와 셀프 플레이는 볼 배합 강화학습(README의 '다음 단계')에서 다룬다.
- 엔진의 전술 영역에는 알려진 차이가 있다(`tactics.md`). 1루 무사의 득점 기대값이 실측보다 낮고(0.803, 실측 0.859), 2·3루 1사 고의사구의 값은 부호가 틀렸다. 시프트 제한 효과는 실측의 3분의 1이다. 견제와 투구 시계도 없다. 이런 곳에 기대는 작전은 엔진의 버릇일 수 있다.
- 홈 이점이 없다(3절).
