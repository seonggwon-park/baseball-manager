# 편집 가능한 데이터 파일

`data/` 아래 JSON 파일은 직접 고쳐도 된다. 지금은 빌드할 때 프로그램에 포함되므로, 고친 뒤 다시 빌드해야 반영된다(설치된 게임에서 바로 고치는 기능은 이후 작업). 파일을 고친 뒤 `cargo test --workspace`를 돌리면 구조가 맞는지 확인할 수 있다(`league_files_are_consistent`, `the_world_has_the_real_structure`, `bundled_books_load`).

## 구단: `data/leagues/us.json`, `kr.json`, `jp.json`

조사 자료([`research/world/`](research/world/))에서 만들었다. **실제**인 것은 도시, 구장 치수·고도·지붕·잔디, 리그와 지구 배치, 모구단 관계, 경기 수다(2026년 구조, 2027년 발표 사항 반영). **지어낸** 것은 구단·리그·구장 이름과 약칭, 색이다. 지어낸 팀명이 조사 자료의 실제 구단명과 겹치지 않는지는 파일을 만들 때 자동으로 확인했다.

| 위치 | 필드 | 뜻 |
|---|---|---|
| 최상위 | `country` | `US`, `KR`, `JP` |
| `leagues[]` | `id`, `level` | 리그 식별자와 단계: `top`(1군·메이저), `aaa`, `aa`, `high_a`, `single_a`, `second`(한국·일본 2군) |
| | `name.ko`, `name.en` | 화면에 보이는 이름 |
| | `games` | 구단당 정규 시즌 경기 수 |
| | `groups[]` | 하위 리그(메이저리그·일본 1군의 두 리그) |
| | `divisions[]` | 지구. `group`은 속한 하위 리그 |
| | `season_2027` | 발표된 2027년 일정(개막일, 마지막 날, 올스타전). 다른 해에는 같은 날짜에서 가장 가까운 같은 요일로 옮겨 쓴다(MLB 개막은 목요일, 마이너리그는 금요일, 올스타전은 화요일) |
| `clubs[]` | `id` | 구단 식별자(다른 필드가 이 값을 가리킨다) |
| | `league`, `division` | 속한 리그와 지구 |
| | `parent` | 모구단 `id`(마이너리그 구단, 2군) |
| | `second_team` | 한국·일본 구단의 2군. 모구단 이름을 그대로 쓴다 |
| | `military` | 군 복무 중인 선수가 뛰는 팀(한국) |
| | `city`, `region`, `country` | 연고 도시, 주·현, 나라 |
| | `name`, `abbr`, `colors` | 팀명, 세 글자 약칭, 주색·보조색(`#rrggbb`) |
| `clubs[].park` | `name`, `capacity` | 구장 이름, 수용 인원 |
| | `elevation_m` | 해발 고도(m). 공기 밀도에 쓰인다. 모르면 `null`(해수면으로 계산) |
| | `roof`, `surface` | `open` / `retractable` / `dome`, `grass` / `turf` |
| | `fence_m` | 펜스 거리(m): 좌익선, 좌중간, 중앙, 우중간, 우익선 |
| | `wall_m` | 담장 높이(m): 좌, 중, 우 |
| | `estimated` | 발표되지 않아 채워 넣은 값의 목록 |

채워 넣은 값의 규칙: 좌중간·우중간 거리가 없으면 파울선 거리에서 중앙 거리까지의 63.5%(메이저리그 평균 330/377/404 ft의 비율), 마이너리그 담장은 8 ft(2.44 m), 한국 2군 구장은 98/113/120 m와 2.5 m, 일본 2군 구장 담장은 3 m다. 서울의 두 구단은 2027–2031년 잠실 올림픽주경기장 안 임시 구장(파울선 95 m, 중앙 124 m)을 쓴다. 담장 높이는 발표되지 않아 4 m로 넣었다.

경기에 쓰이는 것: 지금은 연습 경기의 한국 1군 구단 목록과 홈 구단의 구장(펜스·담장·잔디·고도)뿐이다.

## 이름: `data/names/`

| 파일 | 내용 |
|---|---|
| `ko.json` | 한국 선수: 성(빈도 가중치)과 이름 두 음절 |
| `en.json` | 미국·캐나다 선수: 성과 이름, 한글 표기 |
| `es.json` | 스페인어권(도미니카공화국, 베네수엘라, 쿠바, 멕시코, 푸에르토리코 …) 선수 |
| `ja.json` | 일본 선수. 한국어 화면에서는 성-이름, 영어 화면에서는 이름-성 순서 |
| `zh.json` | 대만 선수. 한국어 화면에서는 성-이름, 영어 화면에서는 MLB 표기처럼 이름-성 순서. 성 가중치는 대만 내정부 2023년 6월 30일 호적 통계(陳 11.21%, 林 8.33%, 黃 6.05%는 공표값, 4–10위는 공표된 상위 10개 합계 52.79%를 순위대로 나눈 근삿값, 11–20위는 근삿값). 이름은 흔한 남자 이름을 같은 가중치로 넣었다(출생 연도별 빈도 자료를 찾지 못했다). 한글은 외래어 표기법(중국어), 로마자는 대만 여권식(웨이드-자일스) |

`w`는 상대 빈도다. `en.json`의 가장 흔한 성 10개는 2010년 미국 인구조사의 인원(천 명 단위)이고, 나머지 가중치는 순위에 따른 근삿값이다. 한글 표기는 외래어 표기법을 따랐다.

## 출생국: `data/people/birthplaces.json`

선수를 만들 때 출생국을 뽑는 비율과, 출생국별로 쓸 이름 파일, 나라 이름(한국어·영어)이 들어 있다.

| 묶음 | 근거 (`docs/research/world/nationality.md`) |
|---|---|
| `mlb` | MLB 2026 개막 로스터(수정 발표)의 출생지. MLB가 '기타'로 따로 적은 3명(일본 1, 페루 1, 영국 1)을 포함 |
| `aaa`, `aa`, `high_a`, `single_a` | MLB Stats API의 2026년 7월 1일 현역 로스터에서 단계별로 센 출생국 |
| `complex` | 애리조나·플로리다 컴플렉스 리그(루키 단계 육성군). 7월 드래프트 전이라 미국 출생 비율이 시즌 전체(약 37%)보다 낮다(약 22%) |
| `academy` | 도미니카 서머리그(도미니카 아카데미 육성군) |
| `kbo_domestic`, `npb_domestic` | 국내 선수 |
| `kbo_foreign`, `kbo_asia` | 2026년 KBO 경기에 나온 외국인 선수·아시아쿼터 선수의 출생국(Baseball-Reference) |
| `npb_foreign` | 2026년 NPB 1군 경기에 나온 외국 출생 선수(Baseball-Reference). 2군·육성 선수는 빠져 있다 |

자료가 '기타'로 묶은 작은 나라들을 나라별로 나눈 비율, 네덜란드령 카리브와 유럽 나라에 영어 이름 파일을 쓰고 브라질에 스페인어 이름 파일을 쓴 것은 가정이다.

## 리그 수준: `data/people/levels.json`

게임을 시작할 때 모든 구단의 로스터를 채우는 기준이다. 수준마다 다음을 적는다.

| 항목 | 내용 |
|---|---|
| `talent` | 메이저리그 능력치 분포의 표준편차 단위 오프셋: 타격, 투구, 수비, 신체, 장타력(타격에 더함), 제구(투구에 더함), 구속(투구에 더함), 선구안(타격에 더함). 일곱·여덟 번째는 없으면 0 |
| `batters`, `pitchers` | 2027년 2월 1일 기준 나이 분포(평균, 표준편차, 최소, 최대). 최대 나이는 그 수준에 들어갈 수 있는 나이의 상한으로도 쓴다 |
| `birthplaces` | 출생국을 뽑을 묶음(`birthplaces.json`) |
| `roster` | 구단당 선수 수. 경기 명단 26명을 넘는 선수는 예비 선수다 |
| `foreign` | KBO·NPB 구단의 외국인 선수: 재능, 출생국 묶음, 맡는 자리(선발 투수 수, 구원 투수 수, 타순 자리), KBO 아시아쿼터 |
| `ball_drag` | 그 수준 자체 경기에서 타구 항력에 곱하는 계수(없으면 1, MLB 공). MLB 투수·타자를 상대로 한 환산 시험은 MLB 공으로 한다 |

수준은 `mlb`, `aaa`, `aa`, `high_a`, `single_a`, `complex`(루키 컴플렉스 육성군), `academy`(도미니카 아카데미 육성군), `kbo`, `kbo2`(퓨처스리그), `npb`, `npb2`(팜)이다. 육성군 두 개는 MLB 구단마다 하나씩 있고 공식 일정을 치르지 않는다.

- 나이 평균은 Baseball-Reference의 2025–2026 리그 평균이다(`docs/research/world/levels.md` 4절: 6월 30일의 만 나이를 출전으로 가중). 미국 수준의 나이 퍼짐과 두 육성군(애리조나·플로리다 컴플렉스 리그, 도미니카 서머리그)의 평균·퍼짐은 MLB Stats API의 2025–2026 선수 기록으로 같은 가중을 써서 쟀다(4.1절; 육성군은 메이저리거 재활 출전인 가장 나이 많은 출전 2%를 뺐다). 더블A·하이A·싱글A의 나이 상한은 그 나이의 99백분위를 2월 1일로 옮긴 값이다(타자 28.7·26.2·24.9세, 투수 30.5·27.8·27.1세; 결정 2026-11-16). 이전의 가정값(32·29·27세)에서는 더 내려갈 수 없는 비유망주가 상한에 쌓여, 30년 뒤 더블A 타자의 37%가 28세 이상이었다(실측 2.9%). 나머지 상한, KBO·NPB의 퍼짐, KBO 퓨처스리그의 나이는 가정이다.
- 로스터 크기는 2026년 규정이다. 트리플A·더블A 28명, 하이A·싱글A 30명, KBO 구단 68명(1군 28명, 퓨처스 40명), NPB 구단 지배하 70명(1군 29명)에 육성 선수 약 19명(2026년 7월 31일 12개 구단 평균). MLB 40인 명단 가운데 26인 밖의 선수는 산하 마이너리그 로스터에 들어간다.
- `talent`는 `bm level`로 맞췄다(2026-11-16). 목표는 그 수준의 2025·2026 공식 기록 평균을 시뮬레이션 MLB 대비 비율로 옮긴 값, 포심 구속과 타구 속도의 MLB 대비 차이(Statcast가 추적하는 트리플A와 싱글A 플로리다 스테이트 리그; 더블A·하이A는 둘 사이를 선형 보간, 가정), MLB 투수 상대 타자의 wRC+(공개된 환산 계수: 트리플A 65, 더블A 52, 하이A 40, 싱글A 30, KBO 56, NPB 64)다. 레벤버그–마쿼트 방법으로, 시드 3개 × 1,500경기의 평균에 맞췄다.
- 미국 마이너리그 네 수준은 타석 접근(Statcast)을 더해 다시 맞췄다: 존 안 투구 비율, 존 안 스윙률, 존 밖 스윙률(2026년, MLB와 마이너리그가 같은 키 기준 존을 쓴 해)과 스윙당 헛스윙률(2025–2026 평균)의 MLB 대비 차이를 시뮬레이션 MLB 값에 더한 목표다. 트리플A와 플로리다 스테이트 리그(싱글A)를 쟀고 더블A·하이A는 둘 사이를 보간했다(가정). `bm level`이 이 네 값을 함께 출력한다.

제구는 투구에, 선구안은 타격에 더한 값이다. 절대값(MLB = 0)으로 보면 미국 마이너리그 네 수준의 투수 제구는 −1.53~−1.56, 타자 선구안은 0(MLB 수준)이다. 존 밖 스윙·헛스윙의 오차는 목표보다 많이 쫓고 많이 헛친다는 뜻이다.

신체는 모든 수준에서 −0.215(트리플A 맞춤값)로 고정했다.

- **선구안 분리(결정 2026-11-16)**: Statcast 2026에서 마이너리그 투수는 MLB만큼 존 안에 던지고(트리플A 47.0%, FSL 47.7%, MLB 47.5%) 타자는 덜 쫓는다(존 밖 스윙 27.7%, 25.7%, MLB 30.5%; `research/world/levels.md` 1.6절; 2025→2026 MLB 존 비율 하락을 존 정의 변경으로 본 해석은 미확인). 이전 맞춤은 타자의 선구안을 타격 격차에 묶어 마이너리그 타자가 MLB보다 더 쫓게 하고(시뮬레이션 싱글A 30.7%), 마이너리그의 많은 볼넷을 투수 제구로 맞췄다(트리플A 제구 절대값 −2.55). 엔진에서 제구 1 SD는 존 비율을 0.5%p밖에 바꾸지 않아 이 격차가 과장됐고, 선수 경력 모델은 30년 뒤 이 격차를 유지하지 못했다(MLB 투수 제구 −0.8 SD, MLB 득점 +0.7/경기). 선구안을 타격 위에 따로 두고 위 네 값을 목표에 더했다.
- **단조 제약(결정 2026-11-16)**: 선구안을 분리하자 싱글A가 위 수준보다 제구·선구안이 좋게 나왔다(FSL의 존 비율과 낮은 존 밖 스윙을 엔진은 MLB만큼 던지는 투수와 MLB보다 참을성 있는 타자로만 재현했다). 선수가 자라며 올라가는 세계는 아래 수준이 더 잘하는 능력을 재현할 수 없으므로, 타격·투구·수비·제구·선구안의 절대값이 바로 위 수준을 넘지 않게 묶고 위에서부터 다시 맞췄다: 트리플A ≤ MLB, 싱글A ≤ 트리플A, 더블A·하이A는 그 사이(하이A ≤ 더블A). 제구와 선구안은 상한에 걸려 네 수준이 거의 같다. 제약을 건 싱글A의 오차(225)는 걸지 않은 맞춤(234)과 비슷했다.
- **신체 고정(결정 2026-11-16)**: 추적 자료가 없는 수준에서는 기록만으로 신체·수비·장타·제구가 서로 보상해 하나로 정해지지 않는다. 처음 맞춤에서 더블A의 신체가 MLB보다 +0.56 SD로 나왔고 사다리가 단조롭지 않았다. 마이너리그 주력 평균은 공개 자료를 찾지 못했다. KBO·NPB와 각 2군에도 같은 근거로 적용했다.
- **구속 오프셋**: 마이너리그 투수의 포심은 MLB보다 1.2–1.6 mph만 느린데 제구·변화구는 크게 뒤처진다. 투구 전체와 묶인 구속으로는 이 구조를 나타낼 수 없어서, 타자의 장타 오프셋처럼 구속 오프셋을 두고 추적된 구속 차이로 정했다.
- **공(결정 '공은 필요할 때만', 2026-11-16)**: 트리플A는 MLB 공을, 그 아래는 별도의 마이너리그 공을 쓴다(Baseball America, `research/world/levels.md` 2절). 플로리다 스테이트 리그의 평균 타구 속도는 2025년 86.4 → 2026년 86.5 mph로 그대로인데 싱글A 홈런율은 1.42% → 2.32%로 뛰어, 공이 바뀌었다는 근거가 있다. 싱글A에서 공의 항력을 재능과 함께 맞춘 결과는 ×1.016으로 MLB 공과 거의 같았다. 더블A·하이A·싱글A(와 두 육성군)에 같은 값을 쓴다. 공은 아래 충돌을 풀지 못했다.
- **알려진 충돌**: 하위 마이너리그에서 Statcast 타구 속도·타석 접근과 공개 환산값(MLB 투수 상대 wRC+)을 함께 맞추지 못한다. 이 엔진에서는 타구 속도가 MLB보다 2 mph 낮은 타자가 MLB 투수를 상대로 wRC+ 60 안팎을 내는데, 실제 싱글A 타자는 타구 속도가 1.9 mph 낮으면서 wRC+가 30이다. 선구안을 MLB 수준으로 두자 마이너리그 타자가 MLB 투수를 상대로도 볼넷을 골라 이 오차가 커졌다(트리플A +4 → +9, 싱글A +12 → +23). 실제로는 마이너리그의 낮은 존 밖 스윙의 일부가 타자를 속이지 못하는 마이너리그 투수 탓일 것이다(MLB 타자가 트리플A에서 MLB로 올라가면 볼넷이 0.84배로 준다; Davenport 2025). 엔진에서 투수 1 SD는 존 밖 스윙을 2.1–2.5%p 바꾼다.
- **2군 타격(가정)**: KBO 퓨처스와 NPB 팜은 환산 자료가 없어서 타격을 1군보다 트리플A→더블A 간격(−0.57)만큼 낮게 고정하고, 나머지를 자체 기록에 맞췄다.
- **외국인 선수(결정 2026-11-16)**: 타자는 MLB 투수 상대 wRC+ 88(KBO로 간 트리플A 타자들의 MLB 환산 EqA .247, MLB 평균 .260; Davenport 2016)에, 투수는 이와 대칭으로 MLB 타자가 그들을 상대로 wRC+ 112를 내도록 맞췄다. NPB 팜의 외국인 예비 선수는 팜 수준과 같게 둔다.
- 루키 컴플렉스와 도미니카 아카데미는 기록이 없어서, 재능을 선수 경력 모델의 정상 상태에서 정한다.

## 성장·노화: `data/people/aging.json`

한 시즌이 끝날 때마다 선수의 능력치가 어떻게 바뀌는지 정한다. 단위는 메이저리그 능력치 분포의 표준편차다. 근거는 [`research/world/aging.md`](research/world/aging.md)에 있다.

| 항목 | 내용 |
|---|---|
| `from_age` | 아래 배열의 첫 칸이 가리키는 나이(16) |
| `growth[i]` | `from_age + i`세 생일 뒤 1년 동안 잠재치까지 남은 차이 가운데 메우는 비율. 29세 이후는 0 |
| `remaining_growth[i]` | 선수를 처음 만들 때 그 나이에서 정점까지 남은 평균 차이. 21세 2.2(Lichtman 2009의 생존자 보정 델타 방법: 21세에서 정점까지 500타석당 +32점) |
| `group_spread` | 한 선수 안에서 능력치 묶음마다 성장의 크기가 다른 정도(상대 표준편차, 가정) |
| `groups.*.attrs` | 같은 곡선을 따르는 능력치. 모든 능력치가 정확히 한 묶음에 들어가야 한다 |
| `groups.*.drift[i]` | 그 나이의 1년 평균 변화(노화). 예: 구속은 26세에서 38세까지 약 −3.75 mph(Petti & Zimmerman 2012), 주력은 23세부터 매년 약 −0.14 ft/s |
| `groups.*.noise` | 1년 변화의 선수별 표준편차 |
| `groups.*.basis` | 근거. `Assumption`은 공개 자료를 찾지 못한 값이다 |

선수 경력 보정(아래)이 정한 값: 묶음별 1년 변동(`noise`)은 근거 자료의 값에 0.731을 곱했다(주력·배트 속도는 해마다의 실측 변화가 있어 ±30% 안에서만 움직였다), 정신력의 나이 성장 0.006/년(가정이던 0.03에서), `group_spread` 0.092, 늦은 성장(`growth_delay`) 제구 3.3년·타격 기술 −1.06년.

구종별 등급은 `stuff` 묶음을 따른다. 잠재치(정점의 능력치)는 선수를 만들 때 정해지고, 해마다 같은 노화·잡음을 받으므로 정점이 지난 선수는 노화 곡선만 따른다.

- 잠재치의 성장은 수준에 따라 평균이 달라지는 능력치에만 붙는다(`develop::grows`). 정신·성격·주자 견제·번트, 투수의 체력(선발·구원 역할로 정해진다)과 타격·주루·포수 능력, 야수의 투구 능력은 생성기가 모든 수준에서 같은 분포로 뽑으므로 성장하지 않는다. 성장을 붙이면 세대가 바뀔수록 MLB 기준보다 높아진다(30년 뒤 MLB 투수의 침착성 +1.2 표준편차, 루키 컴플렉스 투수의 체력 +3.1 표준편차였다).

## 선수 경력: `data/people/careers.json`

오프시즌마다 누가 들어오고, 구단이 누구를 남기고, 누가 떠나는지 정한다(`crates/bm-world/src/career.rs`). `bm careers`로 경기 없이 오프시즌을 수십 년 돌려 결과를 실측과 비교한다.

| 항목 | 내용 |
|---|---|
| `classes` | 새 선수의 종류: 11월 1일 기준 나이 분포, 투수 비율, 출발 재능(`like` 수준의 재능 + `shift`), 앞으로 남은 성장의 배수(`potential`), 출생국 묶음 |
| `drafts` | 리그별 신인 드래프트: 라운드 수, 종류별 비율, 라운드별 계약률. 지명 순서는 전 시즌 성적의 역순 |
| `signings` | 드래프트 밖에서 조직마다 해마다 들이는 선수(MLB 국제 아마추어, NPB 육성 지명, 독립 구단·군 팀) |
| `positions` | 새 야수의 주 포지션 비율 |
| `retirement` | 나이별 스스로 은퇴할 확률(구단이 내보내는 선수와 별도) |
| `keep_potential` | 구단이 남길 선수를 고를 때 현재 능력에 더하는, 잠재치까지 남은 차이의 비율 |
| `board_noise` | 드래프트 순위의 평가 오차(162경기당 득점) |
| `prospect_spread`, `pitcher_potential` | 선수별 성장 배수의 퍼짐(로그 표준편차), 투수의 성장 배수 |
| `starter_share`, `intake_spread` | 새 아마추어 투수 가운데 선발(선발의 체력)로 들어오는 비율, 새 아마추어의 능력치가 종류별 평균 둘레에 퍼진 정도(MLB 표준편차 단위; 모든 수준은 1로 만든다) |
| `intake_tradeoff` | 새 아마추어 타자의 장타력 우위 가운데 컨택·타이밍·배트 컨트롤에서 깎이는 몫(MLB 주전 실측 0.80·0.60·0.50, Statcast 2025)에 더하는 양. 가치로 고르면 올라오는 선수 사이에서 이 맞바꿈이 약해지므로(30년 뒤 MLB의 컨택–장타 상관 −0.57, 실측 주전 −0.71) 아마추어 쪽을 더 강하게 둔다. 모든 수준은 0으로 만든다(결정 2026-11-16: 장타–컨택 맞바꿈 보강 후 재보정) |
| `balance` | 수준의 능력 불균형(타격 기술보다 큰 장타력, 약한 수비, 나쁜 제구)이 정점까지 메워지는 비율 |
| `styles` | 리그마다(`mlb`: MLB 조직, `kbo`, `npb`) 새 아마추어를 옮기는 양(표준편차): 타자의 장타력·타격 기술(컨택·타이밍·배트 컨트롤)·선구안, 투수의 구위(구위·디셉션·구종 등급). 잠재치를 뽑기 전에 능력치를 옮기므로 출발값과 잠재치가 함께 움직인다(결정 2026-11-16: 신인 출발값+잠재치. 잠재치만 옮기면 잠재치가 선수보다 낮은 능력, 곧 수준 균형이 성장을 막는 NPB 장타력과 MLB 선구안은 +0.4를 줘도 30년 뒤 +0.004, +0.037만 움직였다). 리그의 아마추어 야구와 구단 육성이 만드는 구성 차이이며, 가치로만 고르면 모든 리그의 위 수준에 장타력과 선구안이 쌓이므로 리그마다 자기 균형을 지키게 한다. 처음 세계의 선수는 이미 실제 기록에 맞춘 리그 균형을 가지므로 옮기지 않는다 |
| `foreign_candidates` | KBO·NPB 구단이 오프시즌마다 자기 외국인 선수와 비교하는 새 후보 수 |

실측에서 온 값: MLB 드래프트(2021–2025년 3,072명, MLB Stats API)의 학교 구분 비율·지명일 나이·투수 비율·계약률·출생국·포지션, MLB 국제 아마추어 계약 수(2025년 1,011명), KBO 2027 드래프트(110명 중 고졸 87명, 투수 62명), NPB 2025 드래프트(본지명 73명, 육성 43명과 출신 구분). 나머지(신인의 출발 재능·성장 배수·퍼짐·선발 비율, 구단의 판단, 은퇴 확률, 독립 구단·군 팀의 유입, 그리고 `aging.json`의 해마다 변동 크기·정신력의 나이 성장·묶음별 성장 퍼짐과 늦은 성장)는 가정이며, CMA-ES로 보정했다(2026-11-16; 결정: 경기 기록에 직접 맞춤). 목표는 처음 만든 세계에서 오프시즌 30번을 치른 세계가 처음 세계와 같아지는 것이다(사전 시뮬레이션으로 만드는 이력이 이 세계다).

1. 1단계(경기 없이): 수준별 국내 선수의 능력치 평균·퍼짐(타자 14개, 투수 9개; 루키 컴플렉스·아카데미는 뺀다), 수준별 나이(`levels.json`), 드래프트 라운드별 MLB 도달률(Karcher 2017), 도미니카 아마추어의 MLB 도달률 5.4%(Pérez Neró 2019), 평균 데뷔 나이 25.0세(Justice 2020).
2. 2단계: 여기에 5월 31일까지 치른 시즌의 리그별 기록(득점·타율·출루율·장타율·삼진·볼넷·홈런; 기준은 처음 세계의 같은 기간, 시드 4개)을 더하고, 능력치 항은 눈금을 붙잡을 만큼(0.3배)만 남겼다. 리그 가중치는 MLB 3, KBO·NPB 1.5, 마이너리그 1, 2군 0.5다.
3. 루키 컴플렉스와 아카데미의 재능은 이 정상 상태의 평균이다(`levels.json`).

처음 세계의 선수도 같은 출신의 새 선수와 같은 성장 배수(출신별 `potential`, 투수는 `pitcher_potential`을 곱함)를 받는다. 배수 1을 주던 때는 처음 세계의 젊은 선수가 뒤에 오는 선수보다 최대 네 배의 성장을 약속받아, 그 세대가 첫 오프시즌에 MLB를 차지하고(MLB 타자 평균 27.8 → 24.1세) 7년 뒤 MLB 수준보다 1 표준편차 넘게 강해졌다가(10년 뒤 MLB 득점 +1.63/경기) 함께 늙어 빠졌다.

10년 뒤 득점/경기 차이는 MLB +0.98, KBO +0.32, NPB +0.91, 트리플A −0.18, 싱글A −0.51이다(처음 세계의 성장 배수를 고치기 전에는 +1.63, +1.41, +1.81, +0.47, +0.07). 위 표는 성장 배수를 고치기 전의 보정값으로 잰 것이고, 고친 뒤 30년 값은 MLB +0.44, KBO +0.41, NPB +0.95, 싱글A −0.68로 거의 같다.

남은 어긋남과 원인(다음 과제):

- 첫 오프시즌에 구단이 선수를 가치순으로 다시 배치하면서 MLB 타자의 장타력과 선구안이 0.5 표준편차쯤 오른다. 생성기는 수준마다 능력치를 서로 따로 뽑아, 가치로 고른 세계와 구성이 다르다.

- 구단은 선수를 가치(엔진이 잰 득점 가치)로 고르므로, 가치에 크게 들어가는 능력은 위 수준으로 갈수록 처음 세계보다 많아진다. 처음 세계를 만드는 생성기는 이 선택을 모른다. MLB 타자는 컨택 −0.44, 장타력 +0.21, 선구안 +0.42 표준편차가 되어 삼진·볼넷이 늘고, 타격보다 장타가 크게 모자란 NPB 1군(−1.28)은 장타력이 +0.63 올라 장타율이 +.061 높다.
- MLB 투수는 처음 세계보다 0.25–0.48 표준편차 약하다(마이너리그 투수는 맞다). 퍼짐을 맞추면서 꼬리가 얇아져 최상위 투수가 적다. 마이너리그는 반대로 득점이 적다.
- 트리플A와 MLB 사이 제구 격차(1.5 표준편차)는 30년 뒤 약 0.5로 줄어 마이너리그 볼넷이 적다.
- MLB 투수의 침착성은 선택 때문에 +0.4 표준편차 오른다(정신력의 나이 성장은 해마다 0.006으로 거의 0이 됐다).

- 'MLB 도달'은 시즌을 시작할 때 MLB 조직의 상위 49명(2025년 MLB 경기에 나선 선수 1,470명, 구단당 49명)에 든 것으로 센다. 야수와 투수는 표준편차 단위(`ability::per_sd`)로 견준다.
- 각 수준에는 `levels.json` 나이 분포의 최고 나이까지만 들어갈 수 있고, 도미니카 아카데미는 국제 아마추어 계약 선수만 받는다(실제 DSL 선수의 99.5%가 미국 밖 출생). 구단은 이 제한 안에서 남길 선수를 고르고, 위 수준부터 능력순으로 배치한다.
- 마이너리그 FA(결정 2026-11-16): MLB 조직의 마이너리그 선수는 19세 이상에 계약했으면 6시즌, 18세 이하면 7시즌(계약한 해의 일부 시즌 포함)을 채운 오프시즌에 40인 명단 밖이면 FA가 되어 떠난다(2023년 마이너리그 노사협약; `docs/research/world/levels.md` 4.2절). 드래프트 선수는 7월 15일에 계약해 그해를 첫 시즌으로 세고, 국제 아마추어는 1월 15일에 계약해 그해 시즌부터 센다. 40인 명단은 MLB 구단의 선수와 그다음으로 남길 가치(나이 할인 포함)가 높은 선수로 채운다. 처음 세계의 선수는 계약일이 없어 빼고, 아직 FA 시장이 없어 FA가 된 선수는 세계를 떠난다(실제로는 상당수가 다른 조직의 트리플A 자리로 다시 계약한다). 30년 동안 해마다 약 570명이 FA가 된다.
- 한 시즌을 주전으로 뛴 포지션은 익숙함(20점 만점)이 남은 차이의 절반만큼 오른다. 유격수가 3루로, 중견수가 코너로 옮겨 배우는 것이다. 이것이 없을 때는 30년 뒤 MLB 주전의 41%가 익숙하지 않은 포지션을 맡아(익숙함 평균 0.89) 인플레이 타구가 안타가 되는 비율이 올랐다.
- 수준마다 로테이션에 선발 체력을 가진 투수 다섯이 있어야 한다. 더 내려갈 수 없는 선수(나이 상한)가 자리를 채워 모자라면, 그 수준의 가장 약한 구원 투수를 아래 수준의 가장 좋은 선발과 맞바꾼다(구원이 그 수준에 갈 수 있을 때만; 아카데미와 외국인 선수는 빼고). 이 규칙이 없으면 20년 뒤 MLB 30개 구단 가운데 8개, 트리플A 9개가 불펜 투수로 로테이션을 채웠다.
- 구단은 지금 능력에서 나이 할인(`age_discount`)을 뺀 값으로 1군(MLB 조직은 1군과 트리플A)에 들 선수를 먼저 남기고, 수준마다 포수 2명과 선발 체력을 가진 투수 6명(선발 다섯과 예비 하나)을 채운 다음, 나머지를 성장 여지까지 더한 가치 순으로 고른다. 성장 여지를 더한 가치로만 고르면 KBO의 고졸 신인이 1군 주전보다 앞서, 30년 뒤 KBO 1군 타자의 평균 나이가 25.6세(목표 28.7세)로 내려갔다. MLB 조직의 트리플A는 40인 명단과 콜업용 베테랑을 두는 자리라 같이 지킨다(지키지 않으면 트리플A 투수가 25.3세, 목표 27.3세).
- 투수의 가치는 역할과 관계없이 13명 투수진의 평균 이닝 몫(1/13)으로 센다(`ability::STAFF_SHARE`). 역할별 이닝으로 세면 MLB 평균보다 못한 선발이 같은 실력의 구원보다 두 배 넘게 깎인다. 그러면 투수 대부분이 MLB 평균 아래인 조직(KBO)이 선발을 내보내, 30년 뒤 KBO 1군 투수진이 모두 구원 투수가 됐다.
- `age_discount`, `board_noise`는 1 표준편차의 가치(야수 약 72점, 투수 약 9.4점, `ability::per_sd`) 단위라서 야수와 투수에 똑같이 작용한다.

구단 사이의 이적 시장과 연봉은 아직 없어서, 조직을 떠난 선수는 세계에서 떠나고, 나이 든 선수가 계약을 얻기 어려운 현실은 `age_discount`가 대신한다. 근거 자료는 [`research/world/intake.md`](research/world/intake.md)에 있다.

## 세이브 파일 (`bm-save`)

세이브는 SQLite 파일 하나다. 아무 SQLite 도구로나 열어 볼 수 있다. 저장할 때는 옆에 새 파일을 다 쓴 다음 바꿔 넣으므로, 저장이 중간에 끊겨도 반쯤 쓰인 파일이 남지 않는다.

| 표 | 열 |
|---|---|
| `meta` | `key`, `value`: 형식 버전(`format`), 게임 날짜(`date`), 세계를 만든 시드(`seed`) |
| `people` | `id`, `name_ko`, `name_en`, `born`(YYYY-MM-DD), `birthplace`(ISO 국가 코드) |
| `players` | `id`, `data`: 선수의 능력치·숨김 능력치·고유 특성(JSON). 능력치가 늘어도 표 구조를 바꾸지 않으려고 JSON으로 둔다 |
| `rosters` | `club`, `level`, `slot`(`lineup`, `bench`, `rotation`, `bullpen`, `reserve`), `ord`, `player`, `position` |
| `potentials` | `id`, `data`: 선수의 잠재치(정점의 능력치, JSON) |
| `foreign_players` | `id`, `signed_from`: KBO·NPB 구단의 외국인 선수와 그 출생국 묶음(`kbo_foreign`, `kbo_asia`, `npb_foreign`) |
| `careers` | `id`, `data`: 입단 경로(처음부터 있던 선수, 드래프트 연도·라운드·순번, 계약, 외국인), 시즌별 소속·수준, 떠난 연도와 이유(JSON). 은퇴한 선수도 남는다 |

형식 버전이 다른 파일은 잘못 읽지 않도록 거부한다.
