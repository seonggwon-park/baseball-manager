# 리그 구조 조사 원자료

2026년 11월 16일에 조사한 MLB·KBO·NPB의 리그 구조 자료다. 게임 데이터(`data/`)를 만들 때의 근거 자료이며, 게임에 그대로 들어가지 않는다.

- 게임에는 **실제 도시명과 구장 치수만** 쓴다. 파일 안의 실제 구단명·구장명(`real_name`, `ballpark`)은 대조용이다.
- 각 항목의 출처 URL은 `*_notes.md`에 있다.
- **검토 상태: 표본 대조만 마쳤다.** MLB 30개 구장의 치수·고도와 마이너리그 120개 구단의 단계·리그 배치는 알려진 값과 대조해 어긋난 항목을 찾지 못했다. 그 밖의 항목은 `data/`로 옮기기 전에 다시 확인한다.
- 조사에서 확인하지 못한 항목은 파일 안에 `null` 또는 `unconfirmed`로 표시돼 있다(구장 고도는 발표값이 없어 지형 자료에서 읽은 값이다).

| 파일 | 내용 |
|---|---|
| `mlb_clubs.json` | MLB 30개 구단: 리그·지구, 도시, 구장 치수·펜스 높이·고도·지붕·잔디 |
| `milb_clubs.json` | 마이너리그 120개 구단(트리플A·더블A·하이A·싱글A 각 30): 리그, 도시, 상위 구단, 구장 치수·고도 |
| `mlb_notes.md` | 일정 형식(2025년부터 지구 52 / 리그 62 / 인터리그 48경기), 포스트시즌, 로스터 정원, 2026년 경기 규칙(ABS 챌린지 등), 단체협약 상황 |
