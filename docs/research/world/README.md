# 리그 구조 조사 원자료

2026년 11월 16일에 조사한 MLB·KBO·NPB의 리그 구조 자료다. 게임 데이터(`data/`)를 만들 때의 근거 자료이며, 게임에 그대로 들어가지 않는다.

- 게임에는 **실제 도시명과 구장 치수만** 쓴다. 파일 안의 실제 구단명·구장명(`real_name`, `ballpark`)은 대조용이다.
- 게임 데이터 `data/leagues/us.json`, `kr.json`, `jp.json`은 이 자료에서 만들었다. 구단·리그·구장 이름은 지어냈고, 지어낸 팀명이 이 자료의 실제 구단명과 겹치지 않는지 생성할 때 자동으로 확인했다.
- 각 항목의 출처 URL은 `*_notes.md`에 있다.
- **검토 상태: 표본 대조만 마쳤다.** MLB 30개 구장의 치수·고도, 마이너리그 120개 구단의 단계·리그 배치, KBO 10개·NPB 12개 구장의 펜스 거리, 퓨처스리그·팜 리그 팀의 연고지는 알려진 값과 대조해 어긋난 항목을 찾지 못했다. 일정·로스터·경기 규칙의 세부 수치는 `data/`로 옮기기 전에 출처를 다시 확인한다.
- 조사에서 확인하지 못한 항목은 파일 안에 `null` 또는 `unconfirmed`로 표시돼 있다(구장 고도는 발표값이 없어 지형 자료에서 읽은 값이다).
